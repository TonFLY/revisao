O ideal é realizar estes laboratórios em um ambiente de laboratório hospedado. Se quiser realizá-los no seu próprio computador, você pode fazer isso instalando os softwares a seguir. Ao usar seu próprio ambiente, poderão aparecer caixas de diálogo e comportamentos inesperados. Devido à grande variedade de configurações locais possíveis, a equipe do curso não consegue oferecer suporte a problemas que você possa encontrar no seu próprio ambiente.

Instalação no Windows

📝 As instruções abaixo são para um computador com Windows. Você também pode usar Linux ou macOS. Talvez seja necessário adaptar as instruções dos laboratórios ao sistema operacional escolhido.

Windows 11 (sistema operacional)

  1. Instale o Windows 11.

  2. Aplique todas as atualizações disponíveis.

Edge

  1. Instale a versão mais recente do Microsoft Edge em https://microsoft.com/edge.

Git

  1. Baixe e instale o Git em https://git-scm.com/downloads.

    • Use as opções padrão do instalador.

Azure CLI

  1. Baixe e instale o Azure CLI em https://aka.ms/installazurecliwindows.

    • Use as opções padrão do instalador.

Visual Studio Code

  1. Baixe e instale o Visual Studio Code em https://code.visualstudio.com/download.

    • Use as opções padrão do instalador.

SQL Server Management Studio

  1. Baixe e instale o SQL Server Management Studio em https://aka.ms/ssmsfullsetup.

    • Use as opções padrão do instalador.

SQL Server 2022 Developer Edition

  1. Baixe e instale o SQL Server 2022 Developer Edition em https://www.microsoft.com/en-us/sql-server/sql-server-downloads.

    • Use as opções padrão do instalador. Para estes laboratórios, somente o SQL Server Database Engine é necessário.
    • Você pode usar a instância padrão.
    • Você pode usar o modo de autenticação padrão.
