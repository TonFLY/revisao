📚 Como criar questões com o ChatGPT

Você pode pedir ao ChatGPT para criar questões originais e depois importar o arquivo JSON diretamente no Certification Review.

  1. Anexe seus materiais, se tiver: PDF, apostila, slides, anotações ou outros conteúdos de estudo.
  2. Peça ao ChatGPT para usar o material anexado como base e, quando possível, validar tecnicamente as questões em documentação oficial atualizada.
  3. Copie o prompt abaixo, ajuste a certificação e a quantidade de questões.
  4. No final, baixe o arquivo .json e use o botão Importar JSON desta aplicação.

Prompt sugerido:

Estou estudando para a certificação [NOME DA CERTIFICAÇÃO]. Quero que você crie [QUANTIDADE] questões originais para estudo e simulação da prova. Se eu anexei PDFs, apostilas, slides, anotações ou outros materiais nesta conversa, utilize-os como base para identificar os assuntos importantes e o nível de profundidade. Quando possível, pesquise também o guia oficial e a documentação oficial mais atualizada da certificação para validar tecnicamente as questões. IMPORTANTE: - Não copie questões reais, dumps ou questões protegidas de exames. - Crie questões originais no estilo da prova. - Priorize cenários práticos e situações que exijam raciocínio. - Evite perguntas excessivamente óbvias. - As alternativas incorretas devem ser plausíveis. - Distribua as respostas corretas entre A, B, C e D de forma aleatória e equilibrada. - Não deixe todas ou a maioria das respostas corretas na mesma letra. - Evite sequências previsíveis como A, B, C, D, A, B, C, D. - Evite 3 ou mais respostas corretas consecutivas na mesma letra. - Misture questões fáceis, médias e difíceis. - Cubra os diferentes domínios da certificação de acordo com o peso da prova, quando disponível. - Explique por que a resposta correta está correta. - Explique por que cada alternativa incorreta está errada. - Inclua palavra-chave da prova, regra para memorizar e principal pegadinha. - Informe fonte e URL quando houver validação em documentação oficial. - Não use "verified": true se a questão não tiver sido realmente validada. Antes de entregar: 1. Verifique se existe apenas uma melhor resposta. 2. Confirme que o gabarito corresponde à explicação. 3. Confira se as alternativas estão nas posições corretas. 4. Verifique se não existe padrão previsível nas letras corretas. 5. Remova questões duplicadas. 6. Valide a sintaxe do JSON. Entregue o resultado em um arquivo JSON pronto para importação no Certification Review usando EXATAMENTE esta estrutura: { "version": "1.2", "exam": "[NOME DA CERTIFICAÇÃO]", "exportedAt": "DATA_ATUAL_EM_ISO_8601", "total": [QUANTIDADE], "questions": [ { "id": 1, "question": "Enunciado completo da questão", "option_a": "Alternativa A", "option_b": "Alternativa B", "option_c": "Alternativa C", "option_d": "Alternativa D", "correct": "B", "explanation": "Resumo curto da explicação.", "why_correct": "Por que a correta é a melhor resposta.", "why_a_wrong": "Por que A está errada. Se A for a correta, use null.", "why_b_wrong": null, "why_c_wrong": "Por que C está errada.", "why_d_wrong": "Por que D está errada.", "exam_keyword": "Palavra-chave da prova", "memory_rule": "Regra curta para memorizar", "trap": "Principal pegadinha", "source_name": "Microsoft Learn", "source_url": "https://learn.microsoft.com/...", "verified": true, "topic": "Nome do tópico", "difficulty": "medio", "status": "pendente", "created_at": null, "updated_at": null, "last_reviewed": null, "exam": "[NOME DA CERTIFICAÇÃO]" } ] } Regras do JSON: - "correct": somente "A", "B", "C" ou "D". - "difficulty": "facil", "medio" ou "dificil". - "status": sempre "pendente" para novas questões. - Não altere os nomes dos campos. - Não omita os campos. - O JSON final deve ser válido. - Gere o arquivo .json para download. No final, informe também: A: XX B: XX C: XX D: XX e confirme qual foi a maior sequência consecutiva da mesma letra.

Importante: questões geradas por IA devem ser usadas como material de estudo. Para conteúdos críticos, dê preferência a fontes oficiais e questões realmente validadas.
